5. Link Investigation
======================

Commands:

echo "DiskDetective link test" > original.txt

ln original.txt hardlink.txt

ln -s original.txt symlink.txt

ls -li original.txt hardlink.txt symlink.txt

rm original.txt

Result:

The hard link continues to work after the original file is deleted
because it references the same inode.

The symbolic link becomes broken because it references the
original pathname.
